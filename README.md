# RentSport

Програма для обліку прокату спортивного інвентарю. Мій курсовий проєкт з дисципліни «Проєктування автоматизованих інформаційних систем».

**[Завантажити програму для Windows](https://github.com/mx111m/RentSport/releases/latest)**

## Що можна робити

- Додавати клієнтів і знаходити їх за ім’ям або телефоном.
- Вести список інвентарю та перевіряти вільну кількість.
- Оформлювати оренду й повернення, записувати штрафи.
- Передавати спорядження в ремонт і списувати непридатне.
- Переглядати історію оренд та ремонтів.

## Як запустити

1. Відкрий [останній реліз](https://github.com/mx111m/RentSport/releases/latest).
2. У розділі **Assets** завантаж `RentSport-Setup.exe`.
3. Установи програму та відкрий RentSport через меню «Пуск».

Потрібна **Windows 10/11 x64**. .NET уже входить до інсталятора, окремо встановлювати SQLite не потрібно.

## Про розробку

Використав **C#, WPF, .NET 8 та SQLite**. Вихідний код можна відкрити через `Rentt.sln` у Visual Studio.

Дані зберігаються у файлі `rent.db` поруч із програмою. Для резервної копії закрий програму й скопіюй цей файл.

Поки не завершив вхід адміністратора й автоматичний розрахунок штрафів. Зараз штраф указується вручну.
